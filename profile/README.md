## 🏠 하랑은요

하랑은 보호가 끝난 뒤 홀로 세상에 나서는 **자립준비청년**들이 더 이상 혼자가
되지 않도록, 도움을 주고자 하는 **봉사자**와 이어주는 공익법인입니다.
2024년 사회적협동조합으로 시작해 같은 해 12월 공익법인 인가를 받았고,
전 구성원이 20대로 이루어진 팀이 청년의 시선으로 사업을 만들어갑니다.

- ⚖️ **법률 지원** — 법률 자문 매칭 및 소송 지원
- 🏋️ **오프라인 클래스** — 쿠킹클래스(w. 십시일방·서울시 식생활지원센터), 헬스클래스
- 🏡 **주거 프로그램** — 주거 컨설팅, 환경 개선, 주거 관련 교육
- 🎨 **심리 지원** — 온라인 일대일 미술 치료, 심리 상담 및 멘토링

> 하랑은 도움을 주는 존재가 아니라, **같은 세대를 살아가는 동료**로서
> 함께 걷는 존재가 되고자 합니다.

## 🌱 하랑이랑 — 우리가 만드는 플랫폼

오프라인에서 운영진이 직접 이어온 매칭에는 한계가 있었습니다. 그 경험을
더 많은 자립준비청년과 봉사자에게 닿게 하기 위해 만든 온라인 매칭
플랫폼이 **하랑이랑**입니다.

**[harang.social](https://harang.social)** 에서 서비스 중입니다.

| 저장소 | 설명 | 스택 |
|---|---|---|
| [`harang-core-api`](https://github.com/with-harang/harang-core-api) | 백엔드 API | FastAPI · SQLAlchemy · PostgreSQL(Supabase) |
| [`harang-front`](https://github.com/with-harang/harang-front) | 사용자 웹 (harang.social) | Next.js · React · TypeScript |
| [`harang-admin-front`](https://github.com/with-harang/harang-admin-front) | 운영자 백오피스 (admin.harang.social) | React · Vite · TanStack Router/Query |

세 저장소 모두 Railway로 배포됩니다.
